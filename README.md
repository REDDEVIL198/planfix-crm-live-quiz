# Planfix CRM Live Quiz Builder

A Streamlit live quiz app for remote employees. Participants join from different locations through one public URL. The host shares a compact presentation screen in Microsoft Teams and controls the live quiz flow.

## Modes

- Participant: open mode, no PIN required.
- Host: PIN-protected live presentation and controls.
- Admin: PIN-protected quiz editor and quiz manager.
- Results: PIN-protected live leaderboard and CSV export.

## Local Install

```bash
pip install -r requirements.txt
```

## Local Run

```bash
streamlit run app.py
```

On Windows you can also double-click `run_quiz.bat`.

## Host Presentation Mode

Host mode is optimized for Microsoft Teams / TV / projector use:

- compact header with logo, quiz title and stats;
- large centered question card;
- all answer options shown as separated visual cards;
- compact countdown timer and progress bar;
- green correct-answer highlight in reveal mode;
- answer counts and percentages per option;
- top-3 leaderboard cards.

For fullscreen screen share, press `F11` in Chrome. You can also hide Streamlit sidebar with the arrow in the top-left corner.

## Live Quiz Flow

1. Host opens the public app URL.
2. Host selects `Host` and enters Host PIN.
3. Participants open the same public URL and stay in `Participant` mode.
4. Participants enter only name and optional department/team.
5. Host shares the Host screen in Microsoft Teams.
6. Host controls lobby, question start, 10-second timer, reveal, next question and final leaderboard.
7. Host downloads live CSV after the session.

## PIN Configuration

Default values in `default_quiz.json`:

```json
{
  "security": {
    "host_pin": "4444",
    "admin_pin": "9999"
  }
}
```

Preferred Streamlit Cloud secrets:

```toml
[security]
host_pin = "your-host-pin"
admin_pin = "your-admin-pin"
```

Secrets take priority over JSON config.

## Multiple Quizzes

The app now uses:

```text
quizzes/
  active_quiz.json
  planfix_crm_challenge.json
```

On first run, `default_quiz.json` is migrated into `quizzes/planfix_crm_challenge.json` and made active. The active quiz is used by Participant, Host, Admin and Results modes.

Admin → `Квізи` allows you to:

- view available quizzes;
- select active quiz;
- rename quiz title;
- create a quiz from current quiz;
- create a blank quiz;
- upload a quiz JSON file;
- download active quiz JSON;
- duplicate active quiz;
- delete a quiz with confirmation.

Changing active quiz resets the current live session to avoid mixing answers between quizzes.

## Import a Quiz Generated by ChatGPT

1. Ask ChatGPT to create a quiz JSON with the same structure as the current config.
2. Download the JSON file.
3. Open the app.
4. Go to `Admin` → enter Admin PIN → `Квізи`.
5. Use `Імпорт готового quiz JSON`.
6. Enter a safe filename or leave the generated one.
7. Upload and save.
8. The uploaded quiz becomes active immediately and can be used in Host mode.

Uploaded files are validated. Invalid JSON or configs without valid questions/results are rejected and do not replace the current quiz.

## Streamlit Community Cloud Deployment

Use Streamlit Community Cloud to make the quiz available through one public URL. Participants do not need ngrok, a local IP address or any installed software.

1. Create a GitHub repository for this project.
2. Upload the full project folder to the repository, including:
   - `app.py`
   - `requirements.txt`
   - `assets/`
   - `styles/`
   - `quizzes/`
   - `default_quiz.json`
   - `default_quiz.template.json`
3. Open [Streamlit Community Cloud](https://streamlit.io/cloud).
4. Create a new app.
5. Select the GitHub repository.
6. Set the main file path to:

```text
app.py
```

7. Add Streamlit secrets in the app settings:

```toml
[security]
host_pin = "your-host-pin"
admin_pin = "your-admin-pin"
```

8. Deploy the app.
9. Share the public Streamlit URL with participants.

Do not commit real PIN values. Use `.streamlit/secrets.example.toml` as a template only. If Streamlit secrets are missing, the app falls back to the default PIN values in `default_quiz.json`.

## Public Launch Checklist

Before sharing the public URL:

- choose the active quiz in `Admin` -> `Квізи`;
- reset the live session;
- test Host PIN;
- test Admin PIN;
- test Participant join from another browser or incognito window;
- test timer auto reveal;
- test final leaderboard;
- download CSV immediately after the live session.

## Storage Limitation

V1 uses SQLite and local files for live session state, quiz files and CSV export. On Streamlit Community Cloud, local SQLite files and local file changes may reset after restart, redeploy, sleep or container move. For V1, download the CSV immediately after the quiz session.

Future V2 should use Google Sheets or an external database for persistent online results.

## V1 Limitations

- No OAuth.
- No email registration.
- No Planfix API.
- One live session at a time.
- Local SQLite persistence is not guaranteed on Community Cloud.
